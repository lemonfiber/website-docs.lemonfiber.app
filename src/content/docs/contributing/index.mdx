Contributing here runs on a single rule: **every change cites something in the
specification, and that something already exists**. It is the one genuinely
unusual thing about this project, and reading it first will save you a
round-trip.

Everything else is ordinary. Sign your commits off, be decent to the people
around you, and file your issue wherever you can find a box for it — routing is
a maintainer's job, not yours.

## You do not have to write code

The most useful contributions often are not code. Trying it and reporting what
broke, fixing a paragraph that misled you, saying that a screen is hard to read,
answering someone else's question: all of it counts, and all of it follows the
same one rule.
