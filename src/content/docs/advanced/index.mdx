This section is for changing the stack rather than running it. Most of it rests
on one promise: lemonfiber is never the thing standing between you and your
stack. Everything it knows about the services comes from a file you can read and
edit, everything it writes you can edit back, and the stack underneath runs on
plain Docker Compose with no lemonfiber binary anywhere.

Two of these pages describe work that is specified and not yet built. They say so
at the top and link to the specification, rather than describing something that
does not run as though it did.

## Where to go next

If you have not run the stack yet, [running your stack](/running/) comes first —
particularly [forms and slices](/running/forms-and-slices/), which is the
vocabulary the manifest is written in. If something is wrong rather than
missing, [when something is wrong](/fixing/) starts with the doctor. If you want
to build on the boundary rather than the stack, [the API](/api/) describes the
shape everything comes out in.
