---
title: What lemonfiber is
description: A single command that runs a media stack you can reason about.
---

lemonfiber runs a media stack for you: the download clients, the indexers, the
libraries and the web interfaces that sit between a request and a finished
episode on a shelf.

It is one binary. You describe the stack you want in a manifest, and lemonfiber
brings the services up, wires them to each other, and keeps checking that what
it built still matches what you asked for.

## What this site covers

This site is the documentation: how to install lemonfiber, how to run a stack,
what to do when something is wrong, and how the project is built.

It is not the specification. The requirements lemonfiber is written against live
in [their own book](https://lemonfiber.github.io/spec/), which is the single
home for that material.
