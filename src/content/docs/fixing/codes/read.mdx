Raised by the read endpoints `lemonfiber ui` serves, about which read a request named and the query string it arrived with. A read that cannot be answered as it was asked is refused, because answering a different question in its place would read like the answer to this one. `READ-3` answers `404`, and every other one `400`. See [the envelope](/api/the-envelope/).
