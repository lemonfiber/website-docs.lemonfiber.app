Raised while a [plugin](/plugins/) is installed — from a directory, a git source or
the catalogue — updated or removed, and by the
checks an installed plugin contributes to the doctor. An install that fails
part-way is put back: the plugin's files and container go, and the change record
says what was written and reversed.

| Code        | What it means                                                                                                                                                                                                                                                                                  | What to do                                                                                                                            |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `PLUGIN-1`  | A check a plugin contributed to the doctor did not hold. The meaning is the one the plugin declared with its first remedy; the message names the check, the plugin, and each fault found.                                                                                                      | Follow the remedies the plugin declared, in order. Where it declared none, the message says to ask the plugin's author.               |
| `PLUGIN-2`  | What was named is not a plugin lemonfiber can read. Nothing was installed or written.                                                                                                                                                                                                          | Point at the plugin's directory, or at the `plugin.toml` inside it.                                                                   |
| `PLUGIN-3`  | The plugin declares things lemonfiber will not install. The manifest is refused whole — nothing was written — and the message lists every violation at once.                                                                                                                                   | Read what each one says, and take it up with whoever published the plugin.                                                            |
| `PLUGIN-4`  | The record of what is installed could not be read, so lemonfiber will not say that nothing is installed. The message names the file.                                                                                                                                                           | Restore the file from a backup, or move it aside if nothing is installed.                                                             |
| `PLUGIN-5`  | The plugin is already installed. Installing over it would be an update, and an install is not one. Nothing was changed; the message names the version installed.                                                                                                                               | Update it with `lemonfiber plugin update` on the new source, or remove it first.                                                      |
| `PLUGIN-6`  | There is nowhere to install the plugin to: no stack directory has been set up.                                                                                                                                                                                                                 | Run `lemonfiber setup` first, then install the plugin.                                                                                |
| `PLUGIN-7`  | A file the install needed could not be written. The install stopped where it was, and what it had written is on the change record.                                                                                                                                                             | Check the permissions on the stack directory, then install it again. `lemonfiber history` shows what was written.                     |
| `PLUGIN-8`  | The plugin held every proof and could not be recorded as installed, so the install was put back.                                                                                                                                                                                               | Check the permissions on the configuration directory, then install it again.                                                          |
| `PLUGIN-9`  | The plugin's service would not start, so nothing about it could be proved, and the install was put back.                                                                                                                                                                                       | Check that the stack is set up and the container engine is running, then install it again.                                            |
| `PLUGIN-10` | There is no installed plugin by that name, so nothing was removed. The message lists what is installed.                                                                                                                                                                                        | See what is on this machine with `lemonfiber plugin installed`, and remove it by that id.                                             |
| `PLUGIN-11` | The plugin is not installed, so there is nothing to update. Nothing was changed.                                                                                                                                                                                                               | Install it instead, with `lemonfiber plugin install` on the same source.                                                              |
| `PLUGIN-12` | The installed version would not stop, so it was not updated. It is still installed, and nothing else changed.                                                                                                                                                                                  | Check the container engine is running, then try the update again.                                                                     |
| `PLUGIN-13` | The plugin's service would answer on a hostname another plugin already answers on. The proxy will not start with two sites at one address, because that would bring down every route it serves.                                                                                                | Give the plugin's service another hostname in its manifest, or remove the other plugin first.                                         |
| `PLUGIN-14` | The plugin is already installed from another source, and this is a second one for the same name. Two sources for one name are two plugins as far as anybody can tell, and which of them this machine runs is yours to choose. Nothing was written; the message names both sources.             | To run the new source in its place, run `lemonfiber plugin update` on it. To keep the one installed, nothing needs doing.             |
| `PLUGIN-15` | Fetching a plugin from a git source is switched off on this machine, so the source was not asked. Nothing was fetched or installed.                                                                                                                                                            | Install it from a directory instead, or allow it with `lemonfiber config set LEMONFIBER_REACH_PLUGIN_SOURCE on`.                      |
| `PLUGIN-16` | The git source could not be fetched: it did not answer, or would not hand over the revision asked for. Nothing was installed, and the message carries what went wrong.                                                                                                                         | Check the address, and that this machine can reach it, then install it again.                                                         |
| `PLUGIN-17` | The git source holds no branch, tag or commit by the name given. Nothing was fetched or installed.                                                                                                                                                                                             | Name a branch, a tag or a whole commit after the last `@`, or leave it off for what the source serves by default.                     |
| `PLUGIN-18` | The plugin was named for the catalogue to look up, and asking the catalogue is switched off on this machine. Nothing was fetched or installed.                                                                                                                                                 | Install it from a git source or a directory you name instead, or allow it with `lemonfiber config set LEMONFIBER_REACH_CATALOGUE on`. |
| `PLUGIN-19` | The catalogue's index, or its signature, could not be fetched. Nothing was installed, and what is installed already is unaffected; installing from a git source or a directory does not ask the catalogue.                                                                                     | Check this machine can reach github.com and install it again, or install it from its git source.                                      |
| `PLUGIN-20` | The catalogue's index is not signed by the key this build carries: it has no signature, one that does not verify, or none this build has a key to check. Nothing was resolved through it, because an index nobody can show the catalogue signed is no evidence that anybody reviewed anything. | Install it from its git source, where it is installed as unreviewed, or install a lemonfiber that carries the catalogue's key.        |
| `PLUGIN-21` | The catalogue's index is signed and this build cannot read it. Nothing was resolved through it, and nothing was installed.                                                                                                                                                                     | Update lemonfiber, whose newer releases read newer indexes, or install it from its git source.                                        |
| `PLUGIN-22` | The catalogue holds no plugin by that name. Nothing was fetched or installed.                                                                                                                                                                                                                  | Check the name, or write `./<name>` to install the directory of that name.                                                            |
| `PLUGIN-23` | What the catalogue's origin holds at the commit it named is not what the catalogue reviewed: the manifest there is not the one whose digest it signed. Nothing was installed.                                                                                                                  | Install it from its git source if you mean to run it unreviewed, and tell the catalogue's maintainers.                                |

How to read a row, what each severity and state means, and which exit each code leaves with are on [every error by code](/fixing/every-error-by-code/), beside every other family.
