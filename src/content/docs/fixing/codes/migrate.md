Raised by `lemonfiber migrate replace`, which stands in place of a setup already on this machine. It names an offer first, and the offer is answered by that name with `--offer`.

| Code        | What it means                                                                                                                                                                                                                                          | What to do                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| `MIGRATE-1` | What you agreed to is not what standing in place of this setup would stop now. A fresh look offers something else — something started, stopped or changed since you read it — so nothing was stopped. The message names what replacing would stop now. | Ask what replacing would stop again, and read what it says now. |

How to read a row, what each severity and state means, and which exit each code leaves with are on [every error by code](/fixing/every-error-by-code/), beside every other family.
