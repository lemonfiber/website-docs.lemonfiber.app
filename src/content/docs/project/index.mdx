lemonfiber is built in the open, and the facts about it live where they are
already kept current rather than in a page somebody remembers to update. This
section is the way in to those facts: what is finished, what is next, how a
version comes together, and the terms the whole thing ships under.

Nothing here is a status report written by hand. The roadmap is the sequenced
plan, the implementation status is the per-deliverable truth, and each version's
goals are locked in a file before the work is called done.
