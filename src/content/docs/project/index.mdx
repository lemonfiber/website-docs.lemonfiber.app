lemonfiber is built in the open, and the facts about it live where they are
already kept current rather than in a page somebody remembers to update. This
section is the way in to those facts: what is finished, what is next, how a
version comes together, and the terms the whole thing ships under.

Nothing here is a status report written by hand. The roadmap and the changelog
are rendered from the specification's own version manifests and the
implementation status the binary's repository keeps, at the revisions this site
pins — so a figure on either page is a count of marks in a file you can open.
