Nothing on this page is written by hand. Every figure is read from the
specification this site pins: its generated feature board, and the version
manifests behind it.

That has a consequence worth stating plainly. This page is as fresh as the
revision at the foot of it, not as fresh as this morning — the site renders a
pinned checkout so a reader following instructions gets the instructions that
match the release they installed. When the pin moves, these numbers move.

## The version train

Releases run as a train — one version in flight at a time, its goals fixed
before the work starts, and a gate that refuses to tag until every goal is
demonstrably built. [The version train](/project/the-version-train/) explains
the mechanism; this is the train itself.

It is one sequence, and it ends at `1.0.0` — the point where everything
specified is built and the interfaces stop moving. No version ships a stub: a
release refuses while a feature it locks is not yet built.

Each version below names the milestone it serves, how many requirements it
locks, and the features it carries, each with how far the catalogue says it is
built. A version that has already shipped is collapsed — this page is read for
what is coming — and expanding one shows what it carried.
