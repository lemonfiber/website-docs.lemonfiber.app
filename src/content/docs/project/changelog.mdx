Every release below had to earn its tag. A version's goals — a list of accepted
requirement identifiers — are locked before the work starts, and the release
gate refuses to tag until each one is both cited by a merged pull request and
marked done in the implementation status. So the list under a version is not a
summary of what happened to land; it is the set the release was measured
against.

That is why this page counts requirements rather than commits. A commit log
says what was written. The locked goals say what was promised, and the count
beside each release says how much of it was proved.

The list is read from the revisions at the foot of this page, so it is every
release as of those and not as of this morning. A version tagged after them
appears here when the pins move.

## Downloads and release notes

Binaries, checksums and attestations are attached to each tag on the forge, and
the install instructions that come with them are generated per release. Start
from [installing lemonfiber](/start/install/), or go to the
[releases themselves](https://github.com/lemonfiber/lemonfiber/releases) for a
specific tag.
